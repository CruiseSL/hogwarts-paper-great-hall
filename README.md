# 霍格沃茨大礼堂 · 纸雕晚宴

戴上圆眼镜，沿红毯走过四院长桌，去教工席找邓布利多。用方向键移动哈利，拖动环顾，点击场景即可折叠或展开礼堂。触屏设备可以使用画面上的方向键。

[打开可玩的礼堂](https://cruisesl.github.io/hogwarts-paper-great-hall/) · [下载离线项目包](hogwarts-papercraft-project.zip) · [查看制作提示词](prompts.txt)

项目包内含可以离线打开的 `index.html`、场景源码、构建脚本和提示词。源码目录包含重新构建所需的依赖清单和锁文件。

使用 Codex、[Papercraft](https://github.com/xikhar/papercraft) 和 [Three.js](https://github.com/mrdoob/three.js) 制作。两项依赖的 MIT 许可随互动版和项目包附带。本作是非官方的哈利·波特同人练习。
